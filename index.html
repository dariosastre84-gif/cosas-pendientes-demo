Cómo organizar un pendiente
  1. Registrá lo que pasa. Describí un hecho concreto.
  2. Elegí una acción. Empezá por algo que puedas hacer o asignar.
  3. Reservá un momento. Poné una fecha para revisar cómo va.
  4. Comprobá el resultado. Guardá evidencia o ajustá el plan.
